# Limbus-Deutsch-Patch

Inoffizieller, von Fans erstellter Deutschpatch für Limbus Company.

## Installation
1. Lade `Limbus-Deutsch-Patch.zip` herunter.
2. Entpacke den Inhalt des Archivs nach: `LimbusCompany_Data\Lang\`
3. Wähle im Spiel `Select Custom Language` → `Limbus-Deutsch-Patch`.
4. Starte das Spiel neu.
